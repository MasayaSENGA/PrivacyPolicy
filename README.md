# PrivacyPolicy

ブラウザ拡張機能用のプライバシーポリシーを公開するための静的サイトです。GitHub Pages でホストしており、カスタムドメイン `privacy.love-live.jp`（`CNAME` で設定）から配信されます。

## 構成

- `index.html` — プライバシーポリシー本文（日本語・英語）
- `CNAME` — GitHub Pages のカスタムドメイン設定

## 対象の拡張機能

Chrome ウェブストアで公開している次の 6 つの拡張機能の共通のポリシーです。どの拡張機能も、ダッシュボードの「プライバシー ポリシー」欄に https://privacy.love-live.jp/ を登録しています。

| 拡張機能 | ページ内の節 |
| --- | --- |
| チェックひろ（Check-Hiro） | `#check-hiro` |
| コピひろ（Copy-Hiro） | `#copy-hiro` |
| 解錠ひろ（Kaijo-Hiro） | `#kaijo-hiro` |
| にもつひろ（Nimotsu-Hiro） | `#nimotsu-hiro` |
| ギガひろ（Giga-Hiro） | `#giga-hiro` |
| トレひろ（Tre-Hiro） | `#tre-hiro` |

## 公開内容の概要

- 本拡張機能は、個人情報・閲覧履歴・ページの内容などのユーザーデータを収集せず、開発者や第三者に送信しない（にもつひろで、利用者がボタンを押して運送会社のページを開く場合を除く）
- ページ上の情報は、各機能に必要な範囲でブラウザの中で読み取るだけで、記録も送信もしない
- チェックひろ・ギガひろ・トレひろは、利用者が選んだ設定だけを `chrome.storage.sync` に保存する（Chrome の同期が有効なら、同じ Google アカウントの Chrome 間で同期される）。コピひろ・解錠ひろ・にもつひろは何も保存しない
- 拡張機能ごとの取り扱い、第三者への提供、Limited Use の要件への準拠、改定の方法、問い合わせ先（contact@love-live.jp）

## 更新方法

`index.html` を編集して `main` ブランチに push すると、GitHub Pages に自動反映されます。

- 拡張機能の動作（読み取る情報、保存する設定、通信）を変えるときは、その版をストアに提出する前に、このページの該当する節を直してください。各拡張機能の Chrome ウェブストアのプライバシー欄（データの使用の申告）や説明文と食い違わないようにします。
- 改定したら、日本語版と英語版の両方の「最終更新日／Last updated」を書き換えます。
- 拡張機能を追加したときは、「対象」の一覧と「4. 拡張機能ごとの情報の取り扱い」に節を足します（英語版も同じように直します）。
